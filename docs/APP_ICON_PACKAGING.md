# Native launcher packaging

The checked-in approved PNG masters and `recipe.json` under `assets/graphics/app-icon/` are the packaging authority. `tools/build_app_icon.py` is the separate authoring renderer; ordinary native builds never rerender the model or rewrite artwork.

`tools/generators/cook_app_icons.py` validates the opaque 1024-pixel sRGB master and transparent 432-pixel adaptive layers, then generates iOS AppIcon catalogue resources and Android density, adaptive and monochrome resources. Generated resources stay under ignored per-platform build directories. Pillow uses the existing art runtime (`GAME_ART_PYTHON` may select it); no application dependency or binary code is added. Source PNG/recipe and producer hashes are recorded in a small native provenance JSON. Review sheets, GLBs and authoring tools are excluded from this packaging output.

Publication is transactional: invalid inputs preserve the previous complete output, removed outputs regenerate, and unchanged outputs retain their timestamps. The focused producer test covers deletion recovery, stale source rejection and invalid-source preservation. `audit_app_icon.py` binds the installed-package provenance to current approved sources and requires compiled native launcher metadata. Actual platform build, lint and package audits remain the compiler/packaging evidence.
